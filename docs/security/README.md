# Internal security milestone records

The Markdown files in this directory are **internal engineering records** of the
M3B security milestones. They are not part of the Sphinx documentation build
(that build reads `docs/source/` only), are not published, and are retained as
historical evidence of what was designed and tested at the time.

When a statement here differs from current behaviour, the code and
`docs/source/security.rst` are authoritative. Phase 0.8 corrections are
recorded separately; these files are not rewritten to look newer than they are.
